# Vendored exercise data

`exercises.raw.json` is taken verbatim from
[yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db)
(`dist/exercises.json`), which is released under the
[Unlicense](https://unlicense.org/) — public domain, no attribution required,
free for any use.

It is vendored rather than fetched so the app has no runtime dependency on a
third-party host, which the brief requires: the build must work offline and
the only external services are Supabase and Vercel.

Do not edit this file by hand. It is input to `scripts/build-seed.ts`, which
transforms it into `src/db/seed.data.json`. Corrections to derived fields belong
in the override table in that script, so they survive a refresh of the source
data.

To refresh from upstream:

```bash
curl -sS https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json \
  -o data/exercises.raw.json
npm run seed:build && npm run seed:check
```
